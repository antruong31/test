# Stellar Screen Translator

## Project Title

Stellar Screen Translator

## Project Description

Stellar Screen Translator is a decentralized screen translation platform that enables users to instantly capture any area of their screen, extract text using OCR technology, and translate it into their preferred language using AI-powered translation services. Built with Soroban on the Stellar blockchain, the platform provides transparent management of translation history, user credits, and subscription access while ensuring data integrity and decentralized ownership.

The application works similarly to a screen-snipping tool: users select a region of the screen, the text is automatically recognized and translated, and the translated content is displayed in real time.

## Project Vision

The vision of Stellar Screen Translator is to break language barriers by providing a fast, accessible, and decentralized translation experience for users worldwide. By combining OCR, AI translation, and blockchain technology, the platform offers secure translation services with transparent subscription management and immutable usage records.

## How It Works

1. User clicks the translation shortcut or floating button.
2. The application enters screen selection mode.
3. User selects a region of the screen.
4. OCR extracts text from the captured image.
5. AI translation service processes the extracted text.
6. Translated text is displayed instantly.
7. Translation history and usage data can be recorded on Soroban.
